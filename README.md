# **Học sâu**
Repository này được dùng để lưu trữ các thông tin liên quan tới học sâu và đồng thời cũng là nơi nộp bài tập cá nhân của chủ sỡ hữu, các buổi thực hành là của từng tuần khác nhau và không bị trùng lặp, giảng viên [Dr. Đỗ Như Tài](https://dntai.vneasy.net/)

## **Hướng dẫn tải thư viện**
Mở cmd tại mục đang lưu trữ file 'requirements.txt' và nhập vào câu lệnh bên dưới để tự động tải các thư viện và phiên bản được sử dụng của chúng trong repo này.
'''bash
pip install -r requirements.txt
'''
